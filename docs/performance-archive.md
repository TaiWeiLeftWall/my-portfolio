# 演出摄影档案

本次发布包含 49 场、2,904 张演出照片；新增 48 场、2,888 张。
原有 25GR 项目扩充为完整场次，原 16 张及其顺序、项目链接保留。

分类与源目录一致：

- 摇滚现场：GR摇滚节（5）、跨年演出（2）、Livehouse现场（7）。
- 校园演出现场：藤廊音乐会（5）、草坪音乐会（8）、迎新晚会（14）、其他校内演出（8）。

演出页桌面三列、移动端两列；进入父类后才出现细分类。
每场前三张为经过查看的随机封面候选，场次顺序按浏览会话随机。
进入项目先展示照片，项目说明可按需展开。

## 内容和媒体

内容通过现有 CMS SQLite 导入，再生成 `data.js`；不要手动编辑生成的数据。
新大图使用现有 R2 服务，最长边 2,400 px；网站内只存放 720 px 缩略图。
`performance-media.js` 是 URL 到本地缩略图的生成索引，不包含原文件路径、
作者审查记录、账号凭证或 EXIF。新增完整档案不批量进入首页精选。

首页仍为原来的 37 组，新闻摄影保持 EDITORIAL 下的 48 组。
其他类别、视频和商业项目未改动。

原照片未修改。重复导出合并，其他摄影者署名或归属未确认的文件未发布；
不同裁切、黑白版本和不同瞬间保留。原始来源、排除记录和导入前 SQLite
备份仅保存在本地工作记录中，不随网站公开。

## 回归验证

```sh
python -m unittest discover -s upload-tool/tests
node tests/performance_archive_test.cjs
python tests/site_smoke_test.py
```
