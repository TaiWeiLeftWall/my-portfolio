# 沉礁作品集极简呈现改版设计

日期：2026-09-01  
状态：已获用户确认，待实现计划

## 背景

现有网站是纯静态 HTML、CSS 与 JavaScript 作品集。摄影与商业项目由本地 CMS 管理，SQLite 是唯一数据源，`data.js` 与 `commercial.js` 是导出产物。网站目前同时使用黑色顶栏、副导航、独立筛选侧栏、随机/时间线模式、年月筛选、卡片叠放、水印覆盖、灯箱与全站页脚，界面元素比作品本身更抢眼。

本次改版使用 Yundongshu 风格的空间节奏与浏览模型：固定左栏、保留图片原始比例的 Selected Works、多项目单张浏览和克制的 About。只借鉴布局与交互原则，不复制任何他人的内容、名字、媒体或文案。

## 目标

- 让摄影作品成为页面的第一视觉层级。
- 将桌面端导航、分类与身份统一到固定左栏；移动端收敛为顶部披露菜单。
- 首页采用稳定顺序、不裁切的多栏 Selected Works。
- 将组图与商业详情统一为“项目说明 → 单张媒体”的浏览顺序。
- 保留现有内容、公开页面、CMS、部署方式、SEO 信息与图片顺序。
- 保留并强化键盘、焦点、减少动态效果和移动端可用性。

## 非目标

- 不修改或迁移 CMS、SQLite、Cloudflare R2、数据导出结构或托管方式。
- 不手工编辑 `data.js`、`commercial.js`。
- 不新增、删除或改写项目、图片、个人信息、联系方式或商业描述。
- 不重命名公开 HTML 页面或商业项目查询参数。
- 不增加框架、轮播、瀑布流、动画、字体或图标依赖。
- 不实现本次批量导入预演工具与网站数据的自动发布。

## 获准删除的公开呈现与行为

用户已明确选择删繁就简的 A 方案，并授权删除以下当前主页行为：

- 黑色顶栏与其下的副导航组合；
- “随机 / 时间线”显示模式；
- 年份与月份筛选；
- 独立筛选侧栏；
- 图片覆盖标题、计数徽章与装饰性水印覆盖层；
- 重复身份信息与独立全站页脚。

页脚中的社交入口不会丢失，统一收进 About 与侧栏信息区域。原始照片文件不被修改。

## 页面与组件设计

### 作品集外壳

- 1101px 及以上：260px 左栏，主内容 40px 外边距。
- 801–1100px：220px 左栏，主内容 28px 外边距。
- 800px 及以下：垂直布局，顶部导航与主内容各使用 15px 水平边距。
- 外壳占满动态视口高度；左栏与主视图各自控制需要的滚动。
- 页面背景为白色，主文字 `#111`，辅助文字 `#666`，元数据 `#999`，只使用极浅分隔线。
- 保留现有中英文无衬线字体栈，不增加新字体请求。

### Selected Works

- 可用画廊宽度达到 1000px 时为四栏，700–999px 为三栏，小于 700px 为两栏。
- 使用显式列容器，保持数据源与键盘焦点的确定顺序。
- 每个项目固定使用组内第一张图片作为封面，消除随机封面。
- 图片宽度填满列，高度自动，不使用 `object-fit: cover` 或统一卡片高度。
- 概览不叠加标题、日期、水印或计数；项目名称和元数据只在导航或项目说明中出现。
- 可交互缩略图是带可访问名称的真实按钮；悬停设备上仅图片轻微放大，减少动态效果时取消动画。

### 摄影项目浏览器

- 组图映射为一个稳定项目，不增加新的公开 HTML 路由；使用首页内的显式视图状态和可恢复 hash 标识。
- 项目标识由分类、日期和数据索引确定，不写回数据源。
- 第一张幻灯片是项目说明，之后严格按数据源顺序展示全部图片。
- 标题为空时不生成作品名；只显示现有分类、日期、说明与图片数量。
- 图片使用 `max-width: 100%`、`max-height: 85dvh`、`object-fit: contain`。
- 左右语义按钮一次切换一项，首尾循环；计数器不拦截点击。
- 仅浏览器聚焦时处理左右方向键；打开项目后焦点进入浏览器，退出后回到原缩略图。

### 视频

- 保留 `videos.html`、15 个视频及点击后加载 iframe 的性能策略。
- 使用与 Selected Works 相同的留白和排版，不把视频改造成摄影幻灯片。
- 视频控件与链接不会被全屏点击区覆盖。

### 商业项目

- `commercial.html` 保留三个项目及其全部元数据，移除大号宣传导语和独立筛选侧栏。
- 项目卡片不使用阴影、圆角和覆盖文本；封面保持现有比例，信息置于图下。
- 商业详情仍使用 `commercial-detail.html?project=<id>`，第一项为现有客户、标题、说明、年份、分类与联系入口，后续为现有媒体顺序。
- 视频媒体保留原嵌入与控制方式；图片使用单张 `contain` 浏览。

### About

- 桌面最大宽度约 900px，正文约 560px，头像约 300px，间距随视口缩放。
- 保留所有现有段落、合作联系方式和四个社交入口。
- 移除社交卡片、平台 favicon 和厚重装饰，只保留文本链接与清晰焦点状态。
- 移动端在可读时保持紧凑并排，空间不足时自然堆叠。

## 数据流与代码边界

- `common.js` 负责统一外壳、活动导航、移动披露菜单与通用焦点行为。
- `script.js` 只读 `photoGroups` 和 `videos`，负责 Selected Works、分类视图、摄影项目浏览器与视频按需加载。
- `commercial-list.js` 只读商业项目，负责克制概览。
- `commercial-detail.js` 只读查询参数和项目数据，负责说明/媒体序列。
- `style.css` 提供统一外壳、首页、视频和 About 样式；`commercial.css` 只保留商业专属差异。
- 不复制数据到新的手写清单，不新增依赖或第二套设计 token。

## 可访问性与交互约束

- 导航、缩略图、菜单和左右控制必须是语义按钮或链接，并有可见焦点。
- 移动菜单按钮的文字与 `aria-expanded` 来自同一状态。
- 打开项目时移动焦点到浏览器；关闭后恢复到触发缩略图。
- 项目浏览器范围内处理 `ArrowLeft` 与 `ArrowRight`；不拦截输入控件或页面其他区域。
- 指针区域不得覆盖说明中的链接、计数器、导航或其他可聚焦控件。
- `prefers-reduced-motion: reduce` 下取消缩略图缩放和幻灯片淡入，但所有状态变化仍可用。
- 现有图片缺少事实性 alt 文案时使用保守的类别/日期描述，不猜测画面内容。

## 性能与图片策略

- 首页第一张可见作品保持 eager + high priority，其余图片继续 lazy + async decoding。
- 使用原始 R2 URL 和现有懒加载工具；不复制或重新编码图片。
- 不加载不可见项目的大图；项目浏览器只提升当前项及相邻项的加载优先级。
- 数据源没有固有宽高，本次不修改 CMS schema。概览以自然尺寸渲染并使用 `contain-intrinsic-size` 提供保守占位；无法彻底消除首次访问的尺寸确认移动，这是已知限制，不以裁切或固定高度换取稳定。

## 错误与空内容处理

- 没有图片的组不渲染为可交互项目，并保留可诊断控制台提示。
- 标题或说明为空时省略对应元素，不显示占位文案。
- 图片加载失败时显示克制的“图片暂不可用”文本，不显示破损图标或伪造封面。
- 商业封面缺失继续显示现有无封面回退；无效商业项目参数沿用现有返回列表页行为。

### 自动验证

- 先运行现有 Python/JavaScript 测试作为基线。
- 更新 `tests/site_smoke_test.py`，校验所有公开页面、内容数量、URL 与数据连接。
- 增加首页项目浏览器的说明首屏、计数、单步切换、首尾循环、焦点恢复和方向键范围测试。
- 增加移动菜单披露、选择后收起、减少动态效果和无水平溢出测试。
- 保留视频按需加载、商业项目缺图回退、外链安全属性与首图加载优先级测试。

### 浏览器验收

- 桌面：1280×720。
- 移动：390×844。

- 检查 4/3/2 列变化、图片不裁切、侧栏滚动、菜单状态、键盘、焦点、计数、循环切换和 reduced motion。
- 对照改版前审计确认：12 个摄影组、70 张摄影图片、15 个视频、3 个商业项目、10 个商业媒体项、About 全部信息与公开页面均保留。

## 完成标准

- 图片在首页成为第一视觉层级，界面中没有大面积黑色顶栏、筛选面板、随机模式、日期下拉、标题/水印覆盖或重复页脚。
- 桌面使用固定左栏，移动使用默认折叠的顶部菜单。
- Selected Works 使用确定顺序、原比例 4/3/2 栏布局。
- 摄影项目和商业详情采用说明优先、单媒体浏览、可循环的交互模型。
- 内容数量、顺序、页面地址、CMS、数据导出、R2、SEO 与部署保持不变。
- 自动测试、规定视口与交互验收全部通过，最终 diff 不包含用户现有无关改动。
