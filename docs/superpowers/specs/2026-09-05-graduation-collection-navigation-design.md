# 毕业照合集与分组导航设计

日期：2026-09-05

## 目标

在不改变现有品牌风格、公开页面和单组照片浏览方式的前提下，将毕业照素材收纳到“人像 → 毕业照 → 6 组作品”的三级信息架构中。左侧导航参考用户提供的分组节奏，但保留网站现有内容、路由与交互。

## 范围与保留项

- 保留当前静态 HTML/CSS/JavaScript 架构，不引入新框架或前端依赖。
- 保留 `index.html`、`videos.html`、`commercial.html`、`about.html` 等现有公开页面。
- 保留 Selected Works、分类概览、单组说明页、单张切换、键盘操作、图片淡入和 reduced-motion 行为。
- 保留现有 12 组、64 张照片的内容、顺序和链接。
- 原始素材目录只读；不重命名、不移动、不删除原图。
- 不复制参考网站的名称、文案或媒体，只借鉴导航层级和留白节奏。

## 信息架构

桌面端左侧导航保持固定，使用以下层级：

```text
Selected Works

PROJECTS 项目
  人像
    毕业照
  演出
  风光

EDITORIAL
  视频
  商业项目

INFO
  关于我
```

分组标题使用弱化的小字、大写拉丁字母与增大的组间距；中文不转大写。“毕业照”相对“人像”缩进一级。移动端继续由现有“菜单”按钮展开，层级通过字号、缩进和间距表达，不新增二次折叠操作。

## 路由与界面状态

- `index.html#category=portrait` 继续表示全部人像项目。
- `index.html#collection=graduation` 表示毕业照合集概览。
- 合集概览先显示 6 个照片组封面；桌面与平板为 3 列，移动端为 2 列。
- 封面使用各组第一张照片，按自然比例显示，不裁切。
- 点击封面后沿用现有 `#work=<project-id>&slide=<index>` 项目浏览状态。
- 从单组浏览器关闭时，返回打开该项目前的概览状态；从毕业照合集进入则返回 `#collection=graduation`。
- 浏览器前进、后退可在 Selected Works、分类概览、毕业照合集概览和单组浏览之间正确切换。
- “毕业照”为当前项时，子项显示当前态，父级“人像”显示父级激活态，不与可点击的当前项混淆。

## 内容模型

每个照片组增加可选的 `collection` 字段。值为 `graduation` 时，该组属于毕业照合集；其他现有照片组默认为空字符串。合集的显示名和分类映射保持在前端的小型配置对象中，不引入独立内容系统。

为避免未来 CMS 导出覆盖合集标记：

- `photo_groups` 表增加非空 `collection` 字段，默认值为空字符串，并通过现有 schema version 机制迁移。
- 照片组创建、编辑、种子导入、状态 API、批量导入和 `data.js` 导出都保留该字段。
- CMS 照片组编辑器增加可选合集标记，使后续可维护，不影响未分组项目。

## 导入流程

1. 从六个源目录生成确定性文件清单，排除隐藏文件和非图片文件。
2. 对五个新增组使用现有压缩参数与 R2 上传流程；输出用于网站，源文件保持不变。
3. 通过本地 CMS 的幂等创建与上传 API 写入照片组，组分类为 `portrait`，合集为 `graduation`。
4. 将现有“留别III”的合集标记更新为 `graduation`，不更换它的图片 URL、标题、日期和排序。
5. 全部五组上传完整后再导出前端数据，使公开页面不会出现半组内容。

## 失败与恢复

- 上传前记录当前数据库和 `data.js` 状态，使公开数据可恢复。
- 单张上传使用稳定幂等键，可安全重试，不生成重复数据行。
- 某组未完整上传时，不导出前端数据；保留旧站可用状态，并报告失败文件。
- 如组创建后失败，删除未完成的数据库组记录；仅在现有媒体删除能力可确认目标时清理该次上传的 R2 对象，不做广泛删除。
- 图片不可用时沿用现有的“图片暂不可用”降级状态，其他封面与项目仍可交互。

## 前端职责

- `common.js`：将平铺导航数据转换为分组导航模型，渲染标题、项目和嵌套子项，并维护当前项与父级激活状态。
- `script.js`：将 `collection` 带入项目模型，渲染合集概览，解析 `#collection` 状态，并记住单组浏览器的返回位置。
- `style.css`：补充导航分组、嵌套层级、父级激活态和合集 3/2 列布局，继续使用现有变量和断点。
- `data.js`：保存五个新组、现有“留别III”的合集标记以及全部 R2 URL。
- `upload-tool`：迁移并保留照片组的 `collection` 字段，确保后续内容编辑和前端导出不会丢失合集关系。

## 可访问性与响应式

- 导航标题使用非链接文本，导航项使用真实链接，保留键盘焦点样式和 `aria-current` 语义。
- 合集封面使用真实按钮，可见标题和可辨识的 `aria-label`。
- 桌面左栏保持固定且不显示滚动条；移动端展开菜单最高 46dvh，内容超出时可滚动。
- 合集封面和单张图片继续使用加载淡入；`prefers-reduced-motion: reduce` 下去除动画但保留所有状态变化。
- 单张图片继续受限于可用视口宽高，不需滚动才能看完整张。

- 内容数据为 17 组、100 张，毕业照合集恰好 6 组、45 张。
- “留别III”仍为 9 张且 URL 未改变，不存在重复照片组。
- CMS 新建、更新、种子导入、批量导入、状态读取与 `data.js` 导出往返保留 `collection`。
- 导航 DOM 包含 PROJECTS、EDITORIAL、INFO 标题和正确嵌套的“毕业照”链接。
- `#collection=graduation` 显示 6 个封面，可打开各组，关闭后返回合集概览。
- 浏览器前进、后退与键盘切换不回归。

### 浏览器验证

- 桌面 `1280×720`：固定左栏层级、3 列合集封面、当前项、项目开启/关闭和图片容纳正确。
- 移动 `390×844`：菜单展开/收起、2 列封面、触摸目标、无水平溢出和单张图片完整可见。
- 键盘：Tab 焦点可见，Enter/Space 打开封面，方向键切换单组照片，Escape 返回合集概览。
- 动画：默认图片淡入与现有时长一致；reduced-motion 下无淡入且功能不受影响。
